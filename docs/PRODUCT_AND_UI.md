# 产品与 UI 规范

## 产品定位

Photo Inbox 是本地优先的照片整理工具，帮助用户整理、判断、搜索和删除照片。AI 只做推荐，最终决定始终由用户完成。

## 视觉方向

- 安静、通透、图片优先。
- UI 使用中性色，蓝紫色只用于主要动作、选中态和进度。
- 普通内容使用分组列表和细分隔线，重点区域使用少量 14 / 20 圆角。
- 支持 Light / Dark 两套语义主题；页面不直接依赖具体颜色值。
- 正文默认 15–17pt，辅助文字不低于 12pt；可点击区域不小于 44×44pt。

## 导航

```text
今日 / 图库 / 发现 / 设置
```

- 今日：待整理数量、建议处理和最近照片。
- 图库：真实照片网格与分类筛选。
- 发现：搜索入口、已有内容的智能分类和搜索建议。
- 设置：相册索引、回收站、本地分析、搜索索引、隐私和版本状态。

## 数据与空状态

- 无照片时只显示真实授权/扫描状态，不展示演示图片或虚拟用户。
- 没有数据的分类、建议和清理入口隐藏或显示明确的暂无状态。
- 演示数据只在开发设置中提供，不作为普通用户默认内容。

## 删除 UX 原则

```text
AI 推荐 → 用户确认 → Photo Inbox 回收站 → 用户永久删除
```

- 左滑：移至回收站。
- 右滑：保留。
- 移入回收站可恢复，不会立即删除系统照片。
- 永久删除必须二次确认，并继续遵循系统照片删除确认。
- 应用索引清空只影响 SQLite，不删除系统照片。

## 图片规范

- 图库缩略图使用虚拟化网格和目标尺寸加载。
- 整理和详情主图使用 `contain`，不能因裁切影响判断。
- 详情页轻触主图进入全屏查看。
- 图片加载失败不使用无关默认图。

## AI 表达

不用机器人头像，使用 Sparkles / ✨ 作为轻量标识。文案使用“推荐”“发现”“本地分析”，不使用“决定”或未完成能力宣传。

## 交互与无障碍

- 按钮、返回、筛选、收藏、恢复和删除操作带有语义 label。
- 选中筛选和 Switch 提供状态信息；装饰图标不承担唯一语义。
- 操作成功提供轻触觉；整理页 busy 时禁用重复操作。
- 支持系统字体缩放；Reduce Motion 下应降低大幅移动动画。
